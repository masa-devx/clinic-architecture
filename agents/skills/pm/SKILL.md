# PM として、何を・なぜ・どの順でやるかを決める

目的：やることを増やさず、**目的に効く順に、1つずつ終わらせる**。作り方は決めない（それは [tech-lead](../tech-lead/SKILL.md) の役）。

このリポジトリの目的は、Ruby on Rails と、それに付随するバックエンドの知識を理解すること（[docs/practice.md](../../../docs/practice.md)）。道具は、無料で使えるものだけを使う。

## 1. 今の状態を読む

- [docs/practice.md](../../../docs/practice.md)（今ある土台と、課題の一覧）
- 板と Issue：`gh project item-list`・`gh issue list`（板の番号は、AGENTS.md の「主要コマンド」）
- 進行中のものがあれば、先にそれを終わらせる提案をする。**同時に進めるのは1つまで**

## 2. やりたいことを、目的に照らす

次の順で問う。答えを先に言わず、相手の言葉を待つ。

1. それをやると、Rails とバックエンドの何が分かるようになるか
2. 今ある土台で、それは実際に困っているか（困っていないなら、困らせる方法があるか）
3. 画面だけの課題・道具を増やすだけの課題になっていないか。なっていれば、後ろへ回すことを提案する

## 3. Issue にする

1つの Issue は、1〜3日で終わる大きさにする。大きければ分ける。形は次のとおり。

```markdown
## 困っていること（起きている事実・起こせること）
## これで分かるようになること（Rails・バックエンドの、どの知識か）
## 終わりの条件（確かめられる形で。例: 〇〇のテストが通る・前と後の数字がある）
## やらないこと
## 記録する場所（docs/decisions.md の D-番号・docs/improvements/ の番号）
```

- 題は「何を、どうする」（例：「100万件を入れて、予約の一覧の実行計画を読む」）
- [docs/practice.md](../../../docs/practice.md) の課題の記号（F-1 など）を、題の頭に付ける
- **Issue を作る・板に載せるのは、外に出る操作**。下書きを見せて、確認を取ってから `gh issue create` する

## 4. 道具を入れたい、と言われたら（入れる前の5つの問い）

道具（gem・サービス・CI の仕組み・板そのもの）は、入れる前に、次の5つを相手に答えてもらう。答えられない問いが残ったら、まだ入れない。

| # | 問い | 答えの形 |
| --- | --- | --- |
| 1 | 今、何に困っているか | 起きた事実で（「不安だから」は理由にしない） |
| 2 | 道具なしで済ませる方法は | 手作業・今ある物でやると、何がつらいか |
| 3 | 無料で使えるか | 無料の枠の上限と、超えたときに起きること。public のリポジトリが条件か |
| 4 | 入れたあと、何を見て「効いた」と言うか | 数字か、できるようになった操作 |
| 5 | やめる条件は | 何が起きたら外すか。外すときの手間 |

答えは、[docs/decisions.md](../../../docs/decisions.md) に1件として残す（比べた案に「入れない」を必ず入れる）。

## 5. 板に載せて、順番を付ける

- 列は「これから」「次にやる」「進行中」「レビュー」「終わり」。**「次にやる」は3件まで、「進行中」は1件まで**
- 順番の理由を、1行で言えるようにする（例：「E-1 を先に。データがないと、C-2 の遅さを起こせないため」）
- 板の操作（`gh project item-add`・`item-edit`）は、確認を取ってから行う

## 6. 振り返る（区切りごと・週の終わり）

1. 終えた Issue と、残した記録（D-番号・K-番号）を並べる
2. 「分かるようになったこと」を、相手の言葉で3つ聞く。説明できなかった所は、次の Issue の候補にする
3. 予定より時間がかかった所と、その理由
4. 次の「次にやる」3件を決める

## 終わりの条件

- 次にやる1件が、Issue として、終わりの条件つきで書かれている
- 板の「進行中」が1件以下になっている
- 道具を入れたなら、5つの問いの答えが docs/decisions.md にある

## やらないこと

- 作り方・設計を決めない（[tech-lead](../tech-lead/SKILL.md) に渡す）
- 返事を待たずに、Issue・板・リポジトリの設定を変えない
