# クライアントと、届く要望

このサービスを実際に使う人（クライアント）から、使い勝手への不満や「ここをこうしたい」という要望が届く、と想定して進める。要望を受け取って方針を決めるのは PdM（[pdm](../agents/skills/pdm/SKILL.md)）、決まったものをプロジェクトに落とし込んで進めるのはプロジェクトリーダー（[tech-lead](../agents/skills/tech-lead/SKILL.md)）。

> ここにある声・数字は、**推測で作ったもの**。実在の医療機関・人とは関係がない。面接で話すときも、「個人開発で、利用者からの要望を想定して」と言う。

## 1. クライアント（サービスを使う人）

| 人 | 使う画面 | よく言うこと | 本当に困っていそうなこと（推測） |
| --- | --- | --- | --- |
| 患者 | 患者用（スマホ） | 「予約を変えたいのに分かりにくい」「メールが来ない」「当日でも予約したい」 | 自分の予定に合わせて、すぐ動かしたい |
| 医師 | 医師用 | 「受付が済んだか、画面を見に行かないと分からない」「問診を読む時間がない」 | 診察の合間に、次の患者の情報を短く知りたい |
| 院長（医療機関の代表。医師でもある） | 事務スタッフ用・医師用 | 「無断キャンセルを何とかしてほしい」「月の売り上げをすぐ見たい」 | 診察の枠が空く・予定と売り上げが読めない。契約を続けるか決める人 |
| 受付の事務スタッフ | 事務スタッフ用 | 「一覧が遅い」「月末の締めが手作業」「電話の予約を打ち直すのが手間」 | 毎日いちばん長く画面を使う。同じことを何回も打つ・待たされる |

要望は、**解き方の形で来ることが多い**（「CSV で出したい」「通知を増やして」）。その奥にある困りごとを聞き出すのが、PdM とエンジニアの仕事の一部になる。クライアントどうしの要望が、ぶつかることもある（医師は「予約は前日で締めたい」、患者は「当日でも予約したい」）。

## 2. ビジネスサイド（PdM の打ち合わせの相手）

作るか・作らないかは、PdM がビジネスサイドと打ち合わせて決める。

| 人 | 見ているもの | 打ち合わせでよく言うこと |
| --- | --- | --- |
| 事業の責任者 | 医療機関に使い続けてもらうこと（解約を減らす）・売り上げ | 「それで、解約は減るの？」「今期の目標に効くものから」 |
| 営業 | 新しい医療機関の導入 | 「大きな院から、〇〇がないと入れないと言われた」（1院のための機能を頼みがち） |
| CS（問い合わせの担当） | 問い合わせの数と中身 | 「同じ問い合わせが毎週来る」「原因を調べる手段がない」 |

### 目標と数字（推測の値）

| 指標 | 今の値（推測） | 意味 |
| --- | --- | --- |
| **予定どおり診察まで進んだ予約の数**（いちばん大事な数字） | 月 3.4万件 | 患者が来て、医師が診て、会計まで進んだ。医療機関が使い続ける理由になる |
| 医療機関の解約の割合（今期の目標） | 月 2% → 1% にしたい | |
| 無断キャンセルの割合 | 4% | 枠が空き、医師の時間が無駄になる |
| 問い合わせの数 | 月 300件。うち 3割が「ログインできない・メールが来ない」 | |

計測用のデータ（`bin/rails bulk:load`）で出せるものは、実際に SQL で出して比べてよい。

## 3. 届いている要望（PdM の受け箱）

PdM は、ここから1件ずつ取り上げ、方針を決める。**全部は作らない**。作らない・あとで・別の形で解く、も答えのうち。

| # | 誰から | 届いた声 | つながる課題（作るなら） |
| --- | --- | --- | --- |
| R-1 | 受付の事務スタッフ（医師30人の院） | 「予約の一覧を開くと、くるくるが長くて、電話の患者さんを待たせてしまう」 | E-1・E-2 |
| R-2 | 院長 | 「無断キャンセルを何とかしてほしい。前日にメールは行ってるはずなのに」 | D-1・D-2 |
| R-3 | 患者 | 「予約したのに、確認のメールが来ない」 | C-1・D-1 |
| R-4 | 院長・受付 | 「月末に売り上げを見ようとすると、ダッシュボードが重い」 | E-5 |
| R-5 | 受付（CS 経由・緊急） | 「別の院の患者さんの予約が、一覧に出ていた気がする」 | C-2・C-4 |
| R-6 | 医師 | 「患者さんが受付したら、画面を見なくても分かるようにしてほしい」 | D-4・A-4 |
| R-7 | 受付 | 「予約の一覧を CSV で出したい」 | （何に使うのかを聞く） |
| R-8 | 患者 | 「当日でも予約したい」（医師は「前日で締めたい」） | （ぶつかる要望） |
| R-9 | 営業（大きな院の導入の条件） | 「LINE から予約できないと入れない、と言われた」 | （作らない候補） |
