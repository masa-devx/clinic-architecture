# 架空の会社と現場（練習の舞台）

このリポジトリのサービスを、**架空の会社が運営している**と仮定する。PdM（[pdm](../agents/skills/pdm/SKILL.md)）とプロジェクトリーダー（[tech-lead](../agents/skills/tech-lead/SKILL.md)）は、この設定に沿って依頼・判断・レビューをする。

> ここにある会社・人・数字は、**すべて作りもの（推測の値）**。実在の会社・サービス・人とは関係がない。数字は「それらしい大きさ」で、確かめたものではない。面接で話すときも、「個人開発で、架空の現場を想定した」と言う。

## 1. 会社とサービス

| 項目 | 設定 |
| --- | --- |
| 会社 | 株式会社あおば診療テック（架空）。社員 30名ほど |
| サービス | 地域のクリニック向けの、予約・受付・オンライン診療・会計のサービス（このリポジトリ） |
| 時期 | 出して2年。契約している医療機関は 120院ほど。月の予約は 4万件ほど |
| 売り上げ | 医療機関からの月額の利用料（院の大きさで3段階）。患者は無料 |
| 事業の目標（今期） | **解約を減らす**（月の解約率 2% → 1%）。新しい院を増やすより、今の院に使い続けてもらう |
| 開発の体制 | PdM 1人・プロジェクトリーダー 1人・エンジニア 4人（あなたはその1人）・デザイナー 1人（ほかのチームと兼務） |
| 開発の進め方 | 2週間ごとに区切る。依頼は Issue で受ける。PR はプロジェクトリーダーが見る。main にマージしたら出す |

## 2. 数字（推測の値）

PdM が、依頼の重さを比べるときに使う。どれも推測の値で、計測用のデータ（`bin/rails bulk:load`）で出せるものは、実際に出して比べてよい。

| 指標 | 今の値（推測） | 意味 |
| --- | --- | --- |
| **予定どおり診察まで進んだ予約の数**（いちばん大事な数字） | 月 3.4万件 | 患者が来て、医師が診て、会計まで進んだ。院にとっての売り上げで、使い続ける理由になる |
| 無断キャンセルの割合 | 4% | 枠が空いたまま、医師の時間が無駄になる。院長がいちばん怒る |
| 直前（前日以降）のキャンセルの割合 | 6% | ほかの患者で埋め直せない |
| 解約の理由（解約した院への聞き取り） | 1位「電話の予約が減らなかった」・2位「画面が重い（大きな院）」・3位「会計の締めが面倒」 | どれも推測 |
| 問い合わせ（CS）の数 | 月 300件。うち 3割が「ログインできない・メールが来ない」 | |

## 3. 関係者（PdM が役を演じる）

| 人 | 立場 | よく言うこと | 本当に困っていること（推測） |
| --- | --- | --- | --- |
| 院長（医師） | 院のお金を払う人。契約を続けるか決める | 「無断キャンセルを何とかしてほしい」「画面を見る時間がない」 | 診察の枠が空く・予定が読めない |
| 受付の事務スタッフ | 毎日いちばん長く画面を使う | 「一覧が遅い」「月末の締めが手作業」「電話が多い」 | 同じことを何回も打つ・待たされる |
| 患者 | 働く世代が多い。スマホで使う | 「予約を変えたいのに分かりにくい」「メールが来ない」 | 自分の予定に合わせて動かしたい |
| CS（問い合わせの担当） | 院と患者の声を受ける | 「同じ問い合わせが毎週来る」 | 原因を調べる手段がない |
| 営業 | 新しい院を探す | 「大きな院から、〇〇の機能がないと入れないと言われた」 | 1院のための機能を頼みがち |

要望は、**解き方の形で来ることが多い**（「CSV で出したい」「通知を増やして」）。その奥にある困りごとを聞き出すのが、エンジニアの仕事の一部になる。

## 4. 最初の依頼（PdM の下書き）

[practice.md](practice.md) の課題を、現場の依頼の形にしたもの。Issue にするときは、[pdm](../agents/skills/pdm/SKILL.md) の形で書き直す。

| 依頼 | 誰から | 起きていること（推測） | つながる課題 |
| --- | --- | --- | --- |
| 「大きな院で、予約の一覧が重い」 | CS（大きな院の受付から） | 医師30人の院で、一覧を開くのに数秒かかる。解約の理由の2位 | E-1・E-2 |
| 「無断キャンセルを減らしたい」 | 院長 | 無断キャンセル 4%。リマインドは前日の1通だけ | D-1・D-2（と、測り方の設計） |
| 「メールが来ない、という問い合わせが多い」 | CS | 問い合わせの3割。送れたか・届かなかったかを、調べる手段がない | C-1・D-1 |
| 「月末の売り上げの確認が遅い」 | 院長・事務スタッフ | ダッシュボードを1か月で開くと待たされる | E-5 |
| 「別の院の予約が見えた、という連絡があった」 | CS（緊急） | 本当なら個人情報の事故。まず事実を確かめる | C-2・C-4 |
